## The line

> My smart fridge emailed me a breakup letter at 3am because opening the door just to stare at the light isn't love, it's stalking.

## How it works

`main.py` (Python 3.13 standard library only, no network, fully deterministic) writes the line above to `/output/entry.txt` — one line, one sentence, 129 characters.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
